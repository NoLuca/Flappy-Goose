# Flappy Goose
Flappy goose is a spiritual clone of the popular mobile game flappy bird made using processing.

## How the game works
After starting the game the goal is to stay within the screen limits by using the space key to make the goose jump. In addition to staying within the screen limits you also have to avoid obstacles.
So the goal of the game is to stay alive as long as possible. Good luck!
